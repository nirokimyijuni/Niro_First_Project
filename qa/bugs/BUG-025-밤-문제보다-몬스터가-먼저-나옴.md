- 관련 리뷰: -
- 심각도: S3 (엘리 제안: 몬스터는 문제 창이 열린 동안 멈춰 있어서 다치지는 않는다. 창을 닫으면 이미 옆에 와 있다)
- 발견 시점: 시험 / 영역: 규칙
- 재현: 1) 아무 캐릭터로 시작 2) 18:00이 되어 "잠깐 퀴즈!"가 열릴 때 창 왼쪽 뒤를 본다

- 원인 짐작(엘리): `Game::update_combat`이 `combat.update`(밤이면 바로 나오게 하는 차례)를 먼저 하고 맨 끝에서 문제를 연다

- 고칠 사람: 수산나
- 원인: 코드 (`Game::update_combat`이 몬스터 차례를 문제 열기보다 먼저 했다)
- 상태: 닫힘 (2026-11-08 엘리: 수산나가 18:00 프레임에 문제를 먼저 열고 몬스터를 움직이지 않게 고쳤다. 근거: `us075_night_question_comes_before_the_first_monster` 통과(밤이 된 프레임에 몬스터 0마리), 바뀐 `zombie_appears_in_the_same_frame_night_starts` 통과(문제를 닫은 바로 다음 프레임에 첫 좀비), `timeout 300 cargo test` 전체 통과. 부모 승인 "리뷰와 시험을 가볍게"에 따라 밥 재리뷰 없이 시험으로만 확인. 브라우저는 안 봤다)
