# BUG-040 ③(캐기) "잘했어요" 칭찬이 처음 캘 때 곡괭이 안내(4초)에 가려질 수 있다
- 관련 스토리: US-119
- 관련 리뷰: 없음
- 심각도: S4 (제안)
- 발견 시점: 시험
- 영역: 화면
- 원인: 코드 읽기 (view/tutorial.rs `bubble_text`: 곡괭이 안내 4초와 미스 미션 말 3초 동안 말풍선을 숨기고, 칭찬은 1.5초라 통째로 가려진다. 게임·단계는 그대로 ④로 넘어간다)
- 재현: 1) ③에서 처음 나무나 광석을 캔다 2) 곡괭이 안내가 뜨면 칭찬이 안 보이고 4초 뒤 ④ 글이 나온다
- 기대: 칭찬이 보이거나 안내가 대신한다 / 실제: 칭찬 생략 (게임은 막히지 않음)
- 참고: 내 시험(PC 812x375)에서는 ③ 칭찬을 눈으로 못 잡았다 (스크린샷 간격). ④ 칭찬은 보였고 점프한 캐릭터가 말풍선 아래라 안 가렸다. 제안: 안내가 끝난 뒤 칭찬을 남은 시간만큼 보이게 하거나 그대로 둔다 (아이에게 큰 문제 없음)
- 환경: 코드 확인
- 상태: 열림
