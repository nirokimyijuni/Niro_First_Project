# BUG-028 캐는 동안 머리 위 게이지와 "캐기" 표시가 겹침
- 관련 스토리: US-064, US-065
- 관련 리뷰: - (작은 화면 고침, 엘리 시험만)
- 심각도: S4 (엘리 제안: 캐기는 그대로 되고 겉모습만 겹친다)
- 발견 시점: 출시 후 (부모님 발견)
- 영역: 화면
- 원인: 코드 (`view/gather.rs` `draw_usable_tag`가 캐는 동안에도 물건 위 말풍선·E를 그렸다. `mining_progress()`가 Some이면 숨기게 고침)
- 재현: 1) 낮에 동굴에 들어간다 2) 광석 옆에서 E(폰은 캐기 버튼)를 누르고 있는다
- 기대: 캐는 동안 머리 위 게이지만 보이고, 다 캐면 표시가 다시 나온다 / 실제: 게이지와 "캐기"(PC는 "E") 표시가 겹쳐 보였다
- 환경: Chrome PC 크기(960×540) 키보드, 740×360 터치 모드(TouchEvent 흉내), QA 복사본 빌드(지금 작업 폴더 + 자리 옮기기만 더함)
- 상태: 닫힘 (엘리 2026-11-08 재확인)
  - `timeout 300 cargo test` 전부 통과, 실패 0. 새 시험 usable_tag_hides_while_mining_and_progress_bar_clears_hud 통과
  - PC: 캐는 동안 머리 위 초록 게이지만 보이고 "E"는 없다. 다 캐면 철광석 1/2, 다음 쓸 것(출구) 위에 "E"가 다시 나온다
  - 터치 740×360: 캐는 동안 "캐기" 말풍선이 없고 게이지만 보인다. 다 캐면 "나가기"·"캐기" 말풍선이 다시 나온다
  - 점프: 공중에서는 캐지지 않는다. 캐는 중에 뛰면 몸이 광석에서 떨어져 캐기가 멈추고(`keep_mining`이 닿지 않으면 job을 지움) 게이지도 사라진다. 그래서 공중 게이지가 팝업과 겹치는 일은 없다. 땅에 내려와도 버튼을 다시 눌러야 처음부터 캔다 (원래 동작, 이번 고침과 상관없음)
  - 실제 폰은 안 봄
