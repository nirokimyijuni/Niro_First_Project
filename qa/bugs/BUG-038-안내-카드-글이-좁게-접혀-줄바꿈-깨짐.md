# BUG-038 안내 카드 글이 좁은 칸에 접혀 줄바꿈이 깨짐
- 관련 스토리: 아이폰·카톡 화면 꽉 채우기 (스토리 번호 없음, 부모 요청 2026-11-21)
- 관련 리뷰: 없음
- 심각도: S3
- 발견 시점: 시험
- 영역: 화면
- 원인: 코드 (가운데 맞춤을 translateX(-50%)로 해서 카드 너비가 절반으로 줄었다. left:0/right:0/margin:auto + width:fit-content + keep-all로 고침)
- 재현: 1) 폰 가로 667×375로 열고 카톡(KAKAOTALK) 흉내: 글이 5~6줄로 세로로 길어지고 카드 높이 114px (화면의 30%) 2) 세로 375×812도 같음 3) 아이폰 Safari 흉내: "공유 버/튼"처럼 낱말이 중간에서 끊김 4) 홈 화면 안내는 플레이 중에도 아래 가운데에 남아 "I 가방 Esc 멈춤" 안내와 든 무기 자리를 가림 (닫기를 누르면 사라짐)
- 기대: 글이 한두 줄로 읽기 쉽게, 낱말이 끊기지 않게
- 실제: 위와 같음
- 환경: Chrome PC, 667×375 / 375×812 (UA는 JS로 흉내)
- 상태: 닫힘 (엘리 2026-11-21 다시 확인: 가로 667×375는 모든 카드가 한 줄, 세로 375×812는 두 줄(카톡만 네 줄), 낱말 안 끊김. 카드 종류·닫은 뒤 기억(카톡·인스타 sessionStorage, 홈 화면 안내 localStorage)·15초 뒤 사라짐 확인. 카톡 세로 네 줄은 S4 참고)
