# BUG-024 쓰러졌어요 글이 위 정보판 글씨와 겹침
- 관련 스토리: US-069
- 관련 리뷰: REVIEW-014 3번
- 심각도: S4 (엘리 제안: 정보판은 흐려져 있고 "쓰러졌어요"는 잘 읽힌다)
- 발견 시점: 시험 / 영역: 화면
- 재현: 1) 740×360에서 쓰러진다 2) 화면 맨 위를 본다
- 기대: 글씨가 잘리지 않고 다른 글씨와 겹치지 않는다
- 실제: "쓰러졌어요" 윗부분이 흐려진 가운데 정보판(장소, 날짜, 버틴 날) 글씨 위에 놓인다. 쓰러진 화면에 정보판이 그대로 남아 있다. 클리어 화면은 정보판을 숨겨서 겹치지 않는다
- 환경: 내장 브라우저 740×360, QA 임시 빌드 (화면 코드는 dist와 같다)
- 고칠 사람: 로건
- 상태: 닫힘 (2026-11-07 엘리: 고치지 않은 dist 915d266-20261107054640, 740×360과 812×375에서 진짜 밤에 쓰러졌다. "쓰러졌어요"와 점수가 나온 화면에 정보판이 없고 글이 겹치지 않는다)
