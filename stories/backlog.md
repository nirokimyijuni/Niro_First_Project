> M1 범위: 타이틀 → 캐릭터 고르기 → 땅 위에서 걷기·점프·대기, 장애물 넘기.

완료 조건:
- [x] 캐릭터 고르기 화면에 Niro, Ellie, Logan 세 명이 나란히 보이고, 각 그림 아래에 이름이 쓰여 있다
- [x] 처음 들어오면 한 명(맨 왼쪽 Niro)이 골라진 표시(테두리나 화살표)가 있다
- [x] → 를 누르면 표시가 오른쪽 캐릭터로, ← 를 누르면 왼쪽 캐릭터로 옮겨 간다
- [x] 맨 왼쪽에서 ← 를 누르거나 맨 오른쪽에서 → 를 눌러도 화면이 멈추거나 표시가 사라지지 않는다
- [x] Enter나 Space를 누르면 표시된 캐릭터로 게임이 시작된다
- [x] 마우스로 캐릭터를 클릭하거나 화면에서 손가락으로 누르면 그 캐릭터로 게임이 시작된다
- [x] 세 명을 각각 한 번씩 골라 봤을 때, 게임 화면에 나오는 캐릭터가 고른 캐릭터와 같다 (옷 색깔로 확인: Niro 노란 상의, Ellie 파랑·분홍 옷, Logan 빨간 상의)

### US-004 ←/→ 로 걷고, 걷는 쪽을 바라본다  [M1] [완료]
플레이어로서, 화살표 키로 캐릭터를 걷게 하고 싶다. 그래야 땅 위를 돌아다닐 수 있다.
완료 조건:
- [x] → 를 누르고 있으면 캐릭터가 오른쪽으로 걷고, 손을 떼면 멈춘다
- [x] ← 를 누르고 있으면 캐릭터가 왼쪽으로 걷고, 손을 떼면 멈춘다
- [x] 걷는 동안 걷기 동작(다리가 움직이는 그림)이 나온다 — 엘리 확인: 원화가 한 장이라 다리 대신 몸 전체가 통통 튀고 좌우로 기우뚱한다. 걷는 느낌은 충분. 진짜 다리 움직임은 아이가 걷기 그림을 더 그려 주면 가능
- [x] 오른쪽으로 걸으면 캐릭터가 오른쪽을 보고, 왼쪽으로 걸으면 그림이 뒤집혀 왼쪽을 본다
- [x] 걷다가 멈추면 마지막에 걷던 쪽을 계속 보고 있다
- [x] ←와 →를 같이 누르면 캐릭터가 이상하게 떨리지 않는다 (멈추거나 한쪽으로만 간다)
아이에게 물어볼 것: 캐릭터가 걸을 때 발소리가 날까? 난다면 어떤 소리?

### US-005 Space나 ↑ 로 점프한다  [M1] [완료]

완료 조건:
- [x] 땅에 서 있을 때 Space를 누르면 캐릭터가 위로 뛰었다가 다시 땅에 내려온다
- [x] ↑ 를 눌러도 똑같이 점프한다
- [x] 점프하는 동안 점프 그림(동작)이 나온다
- [x] 공중에 있을 때 Space나 ↑ 를 또 눌러도 더 높이 올라가지 않는다 (공중에서 또 점프 안 됨)
- [x] Space를 계속 누르고 있어도 캐릭터가 하늘로 날아가지 않는다
- [x] 점프하면서 ←/→ 를 누르면 그쪽으로 날아가듯 움직이고, 그쪽을 바라본다
- [x] 점프해도 캐릭터 머리가 화면 위로 잘려 나가지 않는다
아이에게 물어볼 것: 점프할 때 캐릭터가 "얍!" 같은 소리를 낼까? 뭐라고 할까?

### US-006 가만히 있으면 대기 동작을 한다  [M1] [완료]
플레이어로서, 키를 안 누르고 있을 때도 캐릭터가 살아 있는 것처럼 움직였으면 좋겠다.
완료 조건:
- [x] 게임이 시작되고 아무 키도 안 누르면 캐릭터가 땅에 서서 대기 동작(숨쉬듯 살짝 움직이기 등)을 한다
- [x] 걷다가 키를 떼면 걷기 동작이 멈추고 대기 동작으로 바뀐다
- [x] 점프하고 땅에 내려와 아무 키도 안 누르면 대기 동작으로 바뀐다
- [x] 대기 동작은 계속 반복되고, 중간에 캐릭터가 사라지거나 깜빡이지 않는다
- [x] 대기 동작 중에도 바라보던 방향(왼쪽/오른쪽)은 그대로다
아이에게 물어볼 것: 가만히 있을 때 캐릭터가 뭘 하면 좋을까? (하품하기, 손 흔들기, 두리번거리기…)

### US-007 땅 위에 넘어야 할 장애물(상자)이 있다  [M1] [완료]
플레이어로서, 길에 놓인 상자를 점프로 넘거나 그 위에 올라서고 싶다. 그래야 걷기만 하는 게 아니라 점프하는 재미가 있다.
완료 조건:
- [x] 게임 화면 아래쪽에 땅이 보이고, 캐릭터는 땅 위에 서 있다 (땅 아래로 빠지지 않는다)
- [x] 땅 위에 상자 같은 장애물이 2개 이상 있다
- [x] 걸어서 상자 옆으로 가면 상자에 막혀 더 못 간다 (상자 속으로 들어가거나 뚫고 지나가지 않는다)
- [x] 왼쪽에서 와도, 오른쪽에서 와도 똑같이 막힌다
- [x] 상자 앞에서 점프하면 상자를 넘어갈 수 있다
- [x] 점프해서 상자 위에 내려오면 상자 위에 서 있을 수 있고, 거기서 걷기·점프·대기가 모두 된다
- [x] 상자 위에서 걸어 끝을 지나면 땅으로 떨어져 내려온다
- [x] 점프로 아래에서 상자에 부딪혀도 상자 속에 끼지 않는다
아이에게 물어볼 것: 장애물은 상자가 좋을까, 아니면 바위·나무 그루터기 같은 다른 게 좋을까? 몇 개 놓을까?

## M2 낮과 밤
> **D44로 바뀜 (부모님 피드백, 임시 값)**: 낮은 실제 5분, 밤은 실제 10분이다. 아래 M2·M3 스토리의 옛 시간은 이 표로 읽는다. 시각 규칙(06:00, 18:00, 00:00)은 그대로다. 노을·새벽은 지금처럼 실제 1분(빨리감기 6초)으로 읽는다 (니로 해석).
>
> | 빨리감기로 06:00부터 잰 시간 | 시계 | 일 |
> |---|---|---|
> | 약 15초 | 12:00 | 해가 가장 높다 |
> | 약 24초 | 15:36 | 노을 시작 |
> | 약 30초 | 18:00 | 밤 |
> | 약 45초 | 21:00 | 이름이 밤 |
> | 약 60초 | 00:00 | 날짜 그대로 |
> | 약 84초 | 04:48 | 새벽 시작 |
> | 약 90초 | 06:00 | 2일째, 버틴 날 1 |
> | 약 180초 | 06:00 | 3일째, 버틴 날 2 |
>
> 시계 빠르기: 보통은 낮 실제 1초 = 게임 **2.4분**, 밤 **1.2분**. 빨리감기면 낮 **24분**, 밤 **12분**. 게임 하루는 실제 **15분**, 빨리감기면 **90초**다.
>
> M2 범위: 낮 10분 / 밤 10분 시계, 해변 하늘 바뀌기(낮 → 노을 → 밤 → 새벽 → 낮), 화면 위 정보판(HUD), 상자 위 코인 줍기, 개발용 빨리감기(F).
> M2에 넣지 않는 것: 몬스터(M4), 저장(최고 기록은 M4, 나머지는 M9), 모바일 조작(M3).
> 수치(낮/밤 길이, 노을·새벽 길이, 코인 다시 생기는 시간, 코인 상한, 빨리감기 배수)는 `game/src/config.rs`에 둔다. 근거: docs/02-plan.md D1, D4, D9~D12.
> 엘리 확인 팁: 빨리감기(F, US-010)를 켜면 낮 10분이 **1분**, 밤 10분도 **1분**, 노을·새벽 1분이 **6초**, 코인 10초가 **1초**가 된다. (D44로 바뀜: 낮 5분이 **30초**, 밤 10분이 **60초**)
> 24시간 시계 기준(D14, US-016): 보통은 실제 1초 = 게임 **1.2분**, 빨리감기면 실제 1초 = 게임 약 **12분**. 빨리감기에서 낮 06:00~18:00 = 약 **1분**, 밤 18:00~06:00 = 약 **1분**, 노을(16:48~18:00)·새벽(04:48~06:00) = 약 **6초**, 게임 하루 24시간 = 약 **2분**. (D44로 바뀜: M2 맨 위 표)

### US-009 낮 10분, 밤 10분 시계가 돈다  [M2] [완료]
니로 메모: 낮·밤 길이는 D44로 바뀌었다 (낮 5분, 밤 10분, 임시 값). 아래는 그때의 조건이다.
플레이어로서, 지금이 낮인지 밤인지, 얼마나 남았는지 알고 싶다. 그래야 밤이 오기 전에 준비할 수 있다.
완료 조건:
- [x] 캐릭터를 고르고 게임이 시작되면 화면 위 정보판에 **낮** 과 남은 시간 **10:00** 이 나온다 (1일째 아침에 시작) (US-016에서 24시간 시계로 바뀜)
- [x] 남은 시간이 1초마다 1씩 줄어든다 (10:00 → 09:59 → 09:58 …). 휴대폰 초시계로 1분 재면 정보판도 1분(09:00) 줄어 있다 (US-016에서 24시간 시계로 바뀜)
- [x] 남은 시간은 언제나 "분:초" 두 자리씩이다 (예: 09:05, 00:07). 음수(-00:01)나 10:00보다 큰 숫자는 나오지 않는다 (US-016에서 24시간 시계로 바뀜)
- [x] 낮이 00:00이 되면 **밤** 으로 바뀌고 남은 시간이 다시 10:00부터 줄어든다 (US-016에서 24시간 시계로 바뀜)
- [x] 밤이 00:00이 되면 다시 **낮** 으로 바뀌고 10:00부터 줄어든다 — 이렇게 끝없이 반복된다 (US-016에서 24시간 시계로 바뀜)
- [x] 걷기·점프 중에도, 가만히 서 있어도 시계는 똑같이 간다
- [x] 빨리감기로 확인: F를 켜고 약 1분 기다리면 낮 → 밤, 또 약 1분 기다리면 밤 → 낮으로 바뀐다. 3번 이상 바뀌어도 멈추거나 숫자가 이상해지지 않는다 (D44로 바뀜: 약 30초에 밤, 약 90초에 낮)
- [x] 다른 브라우저 탭에 30초 갔다가 돌아와도 게임이 멈추거나 낮/밤을 여러 번 한꺼번에 건너뛰지 않는다
엘리 메모(M2): 실제 1분 = 정보판 1분 확인(09:48→08:48). "다른 탭 30초"는 브라우저 패널에서 탭이 숨겨지지 않아, 메인 스레드를 20초 막아 긴 프레임을 흉내 냄 → 시계가 약 3초만 감(한꺼번에 안 건너뜀) + main.rs 단위 테스트. 주의: 초당 4프레임 아래로 느린 기기에서는 시계가 실제보다 느리게 간다(한 프레임 최대 0.25초) — 보통 폰·PC는 괜찮음.

플레이어로서, 나무와 광석 앞에서 버튼을 눌러 캐고 싶다. 그래야 폰에서도 곡괭이 재료를 모을 수 있다. (D5, D16)
완료 조건:
- [ ] PC에서 C 키(처음 값)를 누르고 있으면 바라보는 쪽 가까이 있는 나무나 광석을 캔다
- [ ] 폰에서는 공격 버튼 옆에 큰 **캐기** 버튼이 있고, 누르고 있으면 C 키와 똑같이 캔다 (D16)
- [ ] 캐기 버튼을 누를 때는 공격 버튼처럼 점프하지 않는다 (D59, US-063)
- [ ] 걸으면서 캐기 버튼을 함께 눌러도 손가락이 끊기지 않는다
- [ ] 처음 값: 맨손은 3초, 곡괭이는 1초 걸린다. 맨손이 곡괭이보다 느리다 (D5, `game/src/config.rs`)
- [ ] 다 캐기 전에 손을 떼면 캐기가 멈추고 아무것도 얻지 않는다
- [ ] 가까이에 캘 것이 없으면 눌러도 아무 일이 없다
아이에게 물어볼 것: 캐기 버튼에는 곡괭이, 손 중에 어떤 그림을 그릴까?

## M8 상점
> 코인(최대 5,000)으로 아이템·장비를 산다. 파는 물건은 아이가 정했다 (D55, US-062).
> 새 아이템(D43): 아이가 미스의 상으로 고른 폭탄, 골렘 기구, 이동 알을 먼저 만든다. 아이템을 만든 뒤 상점에서도 팔지 정한다. US-052, US-053이 먼저 있어야 한다.
> 미스 보상은 이제 무기 1개다 (D49). 아래 "함께 쏟아진다"는 만들 때 아이와 다시 정한다.
> 쓰는 법 (니로 해석, 세 아이템 공통): 버튼을 늘리지 않는다. 바꾸기(W 키, 바꾸기 버튼)로 손에 들고 공격(Q 키, 공격 버튼)으로 쓴다. 쓰면 1개 줄고, 0개가 되면 맨손이 된다. 가진 개수는 정보판에 보인다.
> 아래 이름은 설명용이다. 게임 안 이름과 모양은 아이가 정한다. 다른 게임의 이름과 모양을 그대로 쓰지 않는다 (D43).
> 수치는 모두 처음 값이고 `game/src/config.rs`에 둔다. 시간은 실제 시간이라 빨리감기를 켜도 그대로다.

### US-058 폭탄을 놓아서 몬스터를 물리친다  [M8] [할 일]
플레이어로서, 몬스터가 많을 때 폭탄을 쓰고 싶다. 그래야 밤을 더 잘 버틸 수 있다. (D43)
완료 조건:
- [ ] 미스를 찾으면 칼, 도끼, 총과 함께 폭탄 1개가 쏟아진다. 닿으면 주워지고 정보판 개수가 1 는다
- [ ] 폭탄을 들고 공격하면 앞쪽 땅이나 상자 위에 놓이고 개수가 1 준다
- [ ] 처음 값: 2초 뒤 **펑!** 하고 터진다. 120픽셀 안의 몬스터는 체력과 상관없이 쓰러지고, 한 마리마다 경험치 1을 준다
- [ ] 플레이어는 폭탄에 체력이 줄지 않는다
- [ ] 폭탄이 없으면 공격해도 놓이지 않는다
- [ ] 무서운 그림 없이 연기나 별 모양으로 터지고, 새 게임을 시작하면 폭탄이 없다
아이에게 물어볼 것: 폭탄은 어떻게 생겼을까? 이름을 뭐라고 할까? 내 체력도 줄어야 재밌을까? 안테나 2개 시민도 터뜨릴까?

### US-059 기구를 써서 골렘을 불러온다  [M8] [할 일]
플레이어로서, 나를 도와줄 친구를 불러오고 싶다. 그래야 혼자 싸우지 않아도 된다. (D43)
완료 조건:
- [ ] 미스를 찾으면 골렘 기구 1개가 함께 쏟아진다. 닿으면 주워지고 정보판 개수가 1 는다
- [ ] 기구를 들고 공격하면 플레이어 옆에 골렘이 나타나고 개수가 1 준다. 골렘은 한 번에 1마리만 있고, 이미 있으면 기구가 줄지 않는다
- [ ] 처음 값: 골렘은 **30초** 있다가 사라진다
- [ ] 처음 값: 골렘은 가까운 몬스터 쪽으로 걸어가 1초마다 공격력 1로 때린다. 골렘이 쓰러뜨려도 경험치 1을 준다
- [ ] 골렘은 맞아도 쓰러지지 않고 플레이어를 막지 않는다. 상자는 몬스터처럼 넘지 못한다
- [ ] 06:00가 되어도 남은 시간 동안 있다. 새 게임을 시작하면 골렘과 기구가 없다
아이에게 물어볼 것: 우리 게임에서는 이 친구를 뭐라고 부를까? 어떻게 생겼을까? 그려 줄래? 불러오는 기구는 어떤 모양일까? 친구가 나타날 때 뭐라고 말할까?

### US-060 알을 써서 순식간에 집으로 간다  [M8] [할 일]
플레이어로서, 멀리 있어도 순식간에 집으로 돌아가고 싶다. 그래야 위험할 때 도망칠 수 있다. (D43)
니로 메모: 아이는 이 알을 "엔더알"이라고 불렀다. 다른 게임에서 온 이름이라 게임 안 문구와 그림에는 쓰지 않는다.
완료 조건:
- [ ] 미스를 찾으면 이동 알 1개가 함께 쏟아진다. 닿으면 주워지고 정보판 개수가 1 는다
- [ ] 알을 들고 공격하면 캐릭터가 순식간에 집 앞(처음 값 x=3,000)으로 가고 개수가 1 준다. 카메라도 바로 따라간다
- [ ] 도착 자리에는 상자가 놓이지 않아서 끼지 않는다
- [ ] 이미 집 장소(x 2,880 이상)에 있으면 써도 아무 일이 없고 알이 줄지 않는다
- [ ] 시계, 날짜, 코인, 체력, 레벨은 그대로다. 멀어진 몬스터는 [임시-3]대로 사라진다
- [ ] 가는 순간 반짝이는 표시가 나온다. 쓰러진 화면에서는 쓸 수 없다. 새 게임을 시작하면 알이 없다
아이에게 물어볼 것: 우리 게임만의 알 이름을 지어 줄래? 무슨 색이고 어떻게 생겼을까? 그려 줄래? 집 말고 다른 곳으로도 갈 수 있으면 좋을까?

### US-062 상점에서 물건을 사고 광물을 판다  [M8] [할 일]
플레이어로서, 모은 코인으로 좋은 물건을 사고 캔 광물을 팔고 싶다. 그래야 코인을 모으는 재미가 있다. (D54, D55)
완료 조건:
- [ ] 상점을 열면 **총, 물약, 독약, 갑옷**과 가격이 보인다. 폰에서도 손가락으로 고를 수 있다
- [ ] 코인이 충분하면 살 수 있고 코인이 가격만큼 준다. 모자라면 사지지 않고 코인도 그대로다
- [ ] 총을 사면 미스에게 받은 총과 똑같이 쓴다 (US-053)
- [ ] 물약을 쓰면 체력이 찬다. 최대 체력보다 많아지지 않는다
- [ ] 독약을 쓰면 가까운 몬스터에게 독이 퍼져 체력이 조금씩 줄어든다. 초록 구름처럼 무섭지 않게 보인다
- [ ] 갑옷을 입으면 맞을 때 체력이 덜 줄어든다
- [ ] 금, 은, 동을 팔면 코인이 는다. 코인은 5,000을 넘지 않는다 (D11)
- [ ] 철광석은 팔 수 없다 (D54)
- [ ] 코인과 산 물건은 새 게임을 시작하면 없어진다. 저장은 M9에서 한다
니로 메모: 상점 자리, 물약·독약·갑옷의 수치는 아이 답을 듣고 조건에 적는다.
아이에게 물어볼 것: 총, 물약, 독약, 갑옷은 각각 몇 코인이면 좋을까? 금, 은, 동은 각각 몇 코인에 팔까? 상점은 어디에 있을까? 물약을 먹으면 체력이 얼마나 찰까? 독은 어떻게 퍼질까? 갑옷은 어떻게 생겼을까?
