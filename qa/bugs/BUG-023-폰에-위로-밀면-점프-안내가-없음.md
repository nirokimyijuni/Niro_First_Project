# BUG-023 폰에 "위로 밀면 점프" 안내가 없음
- 관련 스토리: US-063 (D59)
- 관련 리뷰: REVIEW-013 1번
- 심각도: S3 (엘리 제안: 부모가 알려 주면 된다. 다만 점프 버튼이 없어져서 혼자 처음 하면 점프를 못 찾을 수 있다)
- 발견 시점: 시험 / 영역: 화면
- 재현: 1) 812×375 또는 740×360에서 터치로 게임을 시작한다 2) 화면을 본다
- 기대: 조작 안내 글에 쉬운 한글로 "위로 밀면 점프" 뜻이 나온다
- 실제: 폰에는 조작 안내 글이 없다. `draw_play`의 안내 글은 `!touch_mode`일 때만 나온다. 왼쪽을 누르기 전에는 점프 방법을 알 수 있는 것이 화면에 없다. 누른 뒤에는 조이스틱 위쪽의 노란 구역과 세모만 보인다
- 환경: 내장 브라우저 812×375, 740×360, dist ae3f66e-20261107025902 (커밋 안 된 `touch.rs`, `input.rs` 포함), TouchEvent 흉내
- 고칠 사람: 로건
- 상태: 닫힘 (2026-11-07 엘리: dist ae3f66e-20261107030500, 812×375에서 터치 모드 낮·밤에 "조이스틱을 위로 밀면 점프"가 화면 아래에 나오고, 쓰러진 화면에서는 안내와 옅은 조이스틱이 빠진다. 엄지를 대기 전 옅은 조이스틱도 보인다. 밤에는 잘 읽히고, 밝은 모래에서도 테두리로 읽히지만 밤보다 약하다)
