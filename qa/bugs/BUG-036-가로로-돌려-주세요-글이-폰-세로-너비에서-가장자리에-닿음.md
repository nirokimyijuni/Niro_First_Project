# BUG-036 "가로로 돌려 주세요" 글이 폰 세로(375 너비)에서 양쪽 가장자리에 닿음
- 관련 스토리: US-035
- 관련 리뷰: 없음
- 심각도: S4
- 발견 시점: 시험
- 영역: 화면
- 원인: (고친 뒤 적는다)
- 재현: 1) 브라우저를 모바일 375×812로 열기 2) 타이틀에서 터치 한 번(가짜 터치 이벤트로 시험) 3) 세로 안내 보기
- 기대: 글이 양쪽에 여유를 두고 보인다 / 실제: "가"와 "요"가 화면 양쪽 끝에 딱 붙어 "요"가 잘려 보일 수 있음
- 환경: 모바일 크기 375×812 (Chrome 에뮬레이션). 이번 변경(touch.rs는 수정 안 됨)과 상관없는 예전 문제일 수 있음
- 상태: 열림 (실제 폰 확인 필요)
