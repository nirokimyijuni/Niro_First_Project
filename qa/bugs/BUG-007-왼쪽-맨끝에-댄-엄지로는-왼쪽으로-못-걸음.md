# BUG-007 왼쪽 맨 끝에 댄 엄지로는 왼쪽으로 못 걸음
- 관련 스토리: US-032, BUG-005를 고치면서 생긴 작은 부작용
- 심각도: 낮음. 오른쪽으로는 걸어지고, 엄지를 떼고 조금 안쪽에 다시 대면 된다. 다만 가로 폰에서 왼손 엄지가 끝에 놓이면 "왼쪽으로 안 가요"가 될 수 있다.
- 재현: 1) 740×360 또는 844×390에서 게임 시작 2) 화면 왼쪽 끝에서 약 14px 안(CSS x 1~10)에 엄지를 댄다 3) 왼쪽으로 화면 끝까지 민다
- 기대: 왼쪽으로 걷는다 / 실제: 안 걷는다 (CSS x 10 → 0, x 1 → 0 모두 이동 0. 같은 자리에서 오른쪽으로 밀면 0.3초에 약 67 걸음)
- 원인: 이제 처음 댄 자리가 중립이라 데드존(가상 21 = 740×360에서 약 14px)만큼 왼쪽으로 밀 공간이 있어야 하는데 화면이 끝난다.
- 8살 눈높이: 실제 엄지가 이 좁은 띠에 닿는 일이 얼마나 잦은지는 실제 폰으로 봐야 한다. 안 생기면 안 고쳐도 된다.
- 고칠 사람: 로건 (고칠지 먼저 판단)
- 환경: 내장 브라우저 모바일 흉내 740×360 배율 2. 터치는 canvas에 TouchEvent를 직접 보내서 흉내 냄
- 상태: 열림
