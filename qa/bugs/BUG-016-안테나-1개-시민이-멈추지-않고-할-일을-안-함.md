# BUG-016 안테나 1개 시민이 멈추지 않고 "자기 할 일"을 안 함
- 관련 스토리: US-057
- 심각도: 보통 (완료 조건을 못 지킨다. 게임이 멈추거나 망가지지는 않는다)
- 재현: 1) 새 게임 2) 일반 시민을 2분 동안 본다 (또는 `timeout 300 cargo test --test m6_ellie -- --ignored walkers_sometimes_stop`)
- 기대: 초당 40픽셀로 걷다가 가끔 멈춰서 두리번거린다
- 실제: 벽이나 장소 끝에서 돌아설 때 말고는 한 번도 멈추지 않는다. 시드 3에서 2분 동안 네 명 모두 멈춘 프레임이 없다. `WalkingCitizen::walk`에 멈추는 상태가 없고, 화면도 늘 `Motion::Walk`로 그린다
- 환경: `cargo test`, Chrome 계열 내장 브라우저 PC 1200×700
- 고칠 사람: 수산나(멈춤 상태), 로건(두리번거리는 그림)
- 상태: 닫힘 (2026-11-07 엘리: 812×375 빨리감기 켠 채 네 명 모두 6.0초 걷고 2.0초 멈춤, 멈추면 왼쪽·오른쪽을 번갈아 봄. `walkers_sometimes_stop` 통과)
