# 개발 계획

## 큰 그림
**"매 단계마다 아이가 직접 해볼 수 있는 게임"** 을 만든다. 처음부터 다 만들지 않고, 작은 단계(마일스톤)마다 링크로 플레이해 보고 다음 단계로 넘어간다.

## 기술 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 엔진 | **macroquad** | Wasm 빌드가 `cargo build` 한 줄, 설정이 거의 없음. bevy는 무겁고 배우기 어려움 |
| 화면 | 2D 옆에서 보는 시점(횡스크롤) | 지침의 "점프로 장애물 피하기"에 맞음 |
| 그림 | 아이 원화를 스캔 → 단순 픽셀/벡터 스프라이트 | 아이 그림의 느낌을 살림 |
| 배포 | GitHub Pages | 무료, 링크 하나로 공유 |
| 모바일 | 화면 위 가상 조이스틱 + 점프/공격 버튼 | 지침의 반응형 요구 |

### 코드 구조 (조슈아 ↔ 로건 경계)
```
game/src/
  main.rs        ← 게임 루프: 입력 → logic 업데이트 → view 그리기
  config.rs      ← 모든 게임 수치 (시간, 공격 횟수, 코인 상한…)
  logic/         ← 조슈아: 화면을 모르는 순수 규칙 (테스트 가능)
    player.rs  monster.rs  combat.rs  clock.rs  level.rs  mine.rs  shop.rs
  view/          ← 로건: 그리기, 애니메이션, UI, 입력, 사운드
    sprites.rs  hud.rs  popup.rs  input.rs  audio.rs
```
`logic`은 macroquad 그리기 함수를 쓰지 않는다 → 엘리가 브라우저 없이 `cargo test`로 규칙을 검사할 수 있다.

## 마일스톤
각 단계 끝에 케빈이 링크를 올리고, 아이가 플레이해 본다.

| # | 이름 | 내용 | 아이와 함께 할 일 |
|---|---|---|---|
| M0 | 준비 | Rust 설치, macroquad "안녕" 화면, GitHub Pages 자동 배포 | 게임 제목 정하기 |
| M1 | 캐릭터가 움직여요 | 캐릭터 선택 화면, 걷기·점프·대기 애니메이션, 땅과 장애물 | 캐릭터 그림 다시 그리기(앞/옆/점프) |
| M2 | 낮과 밤 | 낮/밤 타이머(각 10분), 하늘 색 변화, 남은 시간·생존 시간 표시, 코인 줍기 | 밤 하늘 색 고르기 |
| M3 | 좀비가 나타났다 | 좀비, 공격, 좀비 체력 3, 플레이어 체력 7, 게임오버·다시하기, 최고 기록 저장 | 좀비 모양·이름 정하기 |
| M4 | 스켈레톤과 레벨업 | 스켈레톤 화살 공격, 경험치·레벨업(체력 +5, 몬스터 레벨 상승) | 레벨업 효과음 녹음? |
| M5 | 제작과 동굴 탐험 | 나무·철 모으기, 4×3 제작대에서 곡괭이 만들기, 동굴, 랜덤 광석, 결과 팝업 + 사운드 | 곡괭이 모양 그리기, 광석 종류·희귀도 정하기 |
| M6 | 상점 | 코인(최대 5,000)으로 아이템·장비 구매 | 상점에 팔 물건 정하기 |
| M7 | 폰에서도! | 모바일 조이스틱, 화면 크기 대응, 레벨·코인·아이템 저장, 다듬기 | 가족끼리 누가 오래 버티나 대결 🎉 |

## 결정 사항 (2026-11-01 결정)
원본 지침과 다르게 정한 것. **원본 지침보다 이 표가 우선한다.**

| # | 주제 | 결정 | 남은 질문 |
|---|---|---|---|
| D1 | 낮/밤 시간 | **낮 10분 / 밤 10분** (원본: 5분/20분) | — |
| D2 | 플레이어 체력 | 하트(HP) 방식. **시작 체력 7**, 레벨이 오를 때마다 **+5** (7 → 12 → 17…). 맞으면 몬스터 공격력만큼 줄고, 0이 되면 게임오버 | — |
| D3 | 몬스터 강해지기 | 플레이어 레벨이 오르면 **몬스터 레벨도 오른다.** 몬스터 체력은 레벨이 올라도 그대로. **좀비 체력 3**(3번 때리면 쓰러짐). **좀비 공격력은 5에서 시작해 레벨마다 −2** (레벨 1: 5 → 레벨 2: 3 → 레벨 3: 1). 공격력이 0이나 음수가 되면 안 되므로 **최소 1**로 둔다 — 레벨 3부터는 계속 1 (아이가 "괜찮아"라고 함). (원본의 "공격 횟수 레벨당 +1"은 쓰지 않음) | — |
| D4 | 이기는 방법 | 끝이 없다. **누가 더 오래 살아남는지** 겨룬다 → **버틴 날 수**(밤을 넘긴 횟수)를 기록으로 보여준다 | — |
| D5 | 곡괭이 | **제작대**에서 만든다. 제작대는 **가로 4칸 × 세로 3칸**. 아래 모양대로 **나무 4개 + 철 블럭 2개**를 놓으면 곡괭이가 나온다. **나무는 맵에서** 얻는다. **철은 동굴의 랜덤 광석**에서 얻는다 — 가장 자주 나오는 게 철이고, 다른 광물도 나올 수 있다. 곡괭이가 없을 때는 **맨손으로 캔다. 맨손은 곡괭이보다 느리다** (처음 값: 맨손 3초, 곡괭이 1초 — M5에서 해 보고 조절) | — |
| D6 | 저장 | **가능.** 브라우저 저장 공간(localStorage)에 저장한다. 후보 크레이트 `quad-storage` (macroquad 버전 호환은 M0에서 확인). 최고 기록은 **M3**에, 레벨·코인·아이템 저장은 **M7**에. 다른 기기·다른 브라우저에서는 안 보이고, 브라우저 데이터를 지우면 사라진다 | — |
| D7 | 게임 제목 | **미스 찾기** | — |

### D5 곡괭이 모양 (확정)
```

┌───┬───┬───┬───┐
│ 철 │ 나 │ 철 │   │

│   │ 나 │   │   │
├───┼───┼───┼───┤
│   │ 나 │ 나 │   │
└───┴───┴───┴───┘
```
