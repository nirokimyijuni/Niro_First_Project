# BUG-004 "빨리감기 x10" 표시가 낮·노을 하늘에서 흐릿해 잘 안 보임
- 관련 스토리: US-010 (켜져 있으면 화면에 표시가 보인다)
- 심각도: 낮음 (개발용 기능이라 아이와 할 때는 꺼 둠). 하지만 확인할 때 켜졌는지 한눈에 안 들어옴.
- 재현: 1) 캐릭터 고르고 게임 시작 2) 낮에 F를 누른다 3) 오른쪽 위 코인 판 아래 "⏩ 빨리감기 x10"을 본다
   4) 그대로 노을(남은 시간 01:00 아래)까지 기다려 다시 본다 5) 모바일 크기(375×812)에서도 본다
- 기대: 낮·노을·밤 어디서나 다른 정보판 글씨처럼 또렷하게 읽힌다
- 실제: 표시만 판(반투명 남색 알약) 없이 하늘 위에 바로 주황색으로 그려진다.
  - 글자 채움색(1.0, 0.62, 0.15)과 하늘의 대비: 낮 하늘색 약 **1.2 : 1**, 흰 구름 약 2.1 : 1, 해 근처 약 1.5 : 1,
    노을 주황·분홍 약 **1.1 : 1** (밤 남색에서는 8.5 : 1로 잘 보임). 색값으로 계산.
  - 글자에는 진한 남색 테두리가 있지만 얇아서(가상 1.6px, 모바일에선 실제 1px 아래) 글자 모양을 테두리 혼자 버틴다.
    ⏩ 아이콘은 테두리도 없어서 낮·노을에 하늘에 묻힌다.
  - 화면 캡처로 보면 PC 1200×700에서 낮에는 읽히지만 옆의 흰 글씨 정보판보다 확실히 흐리고, 노을 때는 더 흐리다.
    모바일 크기에서는 글씨가 약 12px라 낮에는 거의 읽기 어렵다 (BUG-003과 같은 원인도 겹침).
  - 그리고 표시 바로 아래에 해(노란 원·빛)가 있어 더 묻힌다.
- 제안: 다른 정보판처럼 반투명 남색 알약 판 위에 그리기 (가장 간단). 해와 겹치지 않게 자리 조정.
- 고칠 사람: 로건 (view/hud.rs `draw_hud`의 빨리감기 부분)
- 환경: Claude 브라우저 패널(Chromium) PC 크기 1200×700 / 모바일 크기 375×812, http://localhost:4000
- 고친 방법: 빨리감기 표시를 다른 정보판과 같은 반투명 남색 알약 판(높이 48) 위에 주황 ⏩ 아이콘 + 흰 글씨(테두리, 크기 34)로 그리고, 정보판 줄 바로 아래 해 빛(x 791~909) 왼쪽(판 오른쪽 끝 x 775)으로 옮김 (view/hud.rs).
- 재확인 (2026-11-06, 엘리, 라이브 ac750ad): PC 1200×700과 740×360에서 아침·낮·오후·노을·밤·새벽 모두 남색 판 위 흰 글씨가 또렷하다. 해가 판 뒤로 지나가도 글자는 읽힌다.
- 상태: 닫힘
