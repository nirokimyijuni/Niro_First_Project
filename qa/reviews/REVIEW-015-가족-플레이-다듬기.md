- 리뷰한 사람: 밥 (코드 리뷰어)

- 대상: a6a51c0 뒤 커밋 안 된 `game/src`, `game/tests`

## 이 변경이 하는 일

미스가 칼 → 도끼 → 총 순서로 무기를 주고, 총은 칼·도끼가 다 있을 때만 10%로 나와요. 몬스터는 10초마다 2마리, 모두 6마리, 좀비 4마리로 줄었어요. 나무 위 미스의 무기는 땅까지 떨어지고, 총은 벽을 뚫지 못하며 빛줄기도 벽에서 멈춰요.

## 잘한 점

- **`clear_reach` 하나로 끝냈어요.** 벽까지의 거리를 먼저 구해서 `attack_with`의 `range`로 넘기니까, 몬스터와 폭발 시민, 빛줄기가 모두 같은 값을 써요. 판정과 그림이 어긋날 수 없어요.
- **REVIEW-009 4번의 절반이 풀렸어요.** 구멍 안에서는 구멍 옆벽이 막아서 땅 위 몬스터를 총으로 쏠 수 없어요.

## 첫 밤 "맞서 싸우기" 35 → 11의 답

**둘 다예요. 대부분은 측정 코드 문제이고, 작지만 진짜 게임 효과도 있어요.** 숫자는 버틴 판이에요 (100판, 진짜 `how_hard_the_first_night_is`를 복사본에서 고쳐 돌림).

| 측정 코드 | 옛 값 (6초, 8, 5) | 새 값 (10초, 6, 4) |
|---|---|---|
| 지금 그대로 (날것의 거리) | 35 (알려 준 값) | 11 |
| 고리 거리로 고침 | 76 | 52 |

1. **측정 코드 문제 (11 → 52).** `m6_measure.rs:247~249`가 `(a - me).abs()`와 `target < me`를 써요. 시작 자리 x=120에서 왼쪽 몬스터는 x 3,000쯤이라 멀리 있다고 보고, 등을 돌린 채 오른쪽으로 가요. 다른 봇으로 재 보니 25~32%의 프레임에서 쪽이 틀렸어요. 게임의 몬스터와 주인공 판정은 고리를 잘 써요. 틀린 것은 봇뿐이에요.
2. **진짜 게임 효과 (76 → 52).** 고친 측정에서도 몬스터가 줄면 나빠져요. 까닭은 레벨 업이에요. 맞서 싸우는 봇은 레벨이 올라야 체력이 다 차고 5가 늘어나는데 (D41), 몬스터가 줄면 해치울 수가 줄어요. 같은 측정에서 나온 몬스터는 평균 16.8 → 9.4, 레벨 업은 평균 2.2 → 1.1로 절반이 됐어요. 버그가 아니라 규칙끼리 만나서 생긴 일이에요. 몬스터가 적으면 정신은 덜 없지만 회복 기회도 줄어요.

참고: 내가 따로 쓴 봇은 버틴 수가 측정보다 낮게 나왔고 (고리 거리 500판에 옛 값 123, 새 값 34), 왜 차이가 나는지는 못 밝혔어요. 쪽이 틀린 것과 새 값이 나빠지는 방향은 같아요. 위 표는 진짜 측정 코드의 숫자예요.

## 물어본 것의 답

**무기 순서와 총 10%**: 맞아요. 칼, 도끼, 그다음 10%이고, 총을 가졌거나 땅에 있으면 안 나와요.

**무기가 땅까지 떨어지기**: 맞아요. 여섯 곳 모두 표대로 확인해요. 나무 꼭대기는 땅, 지하는 구멍 바닥, 산꼭대기는 계단 위예요. 15초는 땅에 닿은 뒤부터 세요.

**`attack_reach`·`clear_reach`**: 맞아요. 이음매 너머 벽, 몸이 이음매에 걸친 경우, 구멍 안, 발밑 상자, 낮은 상자 위로 쏘기, 폭발 시민 모두 시험이 있어요. 벽에 붙으면 거리 0인데, 몸에 겹친 몬스터는 여전히 맞아요. 맨손·칼·도끼는 그대로예요 (BUG-010).

**몬스터 수 줄이기**: 코드는 맞아요. 값 세 개만 바뀌었어요. 시험이 값을 안 붙들어요 (1번).

**옛 시험**: 대부분 그대로거나 더 세졌어요. `weapon_falls...`는 기대 높이를 곳마다 적어서 세졌어요. 첫 무기가 뭐든 나오는지 보던 줄은 규칙이 바뀌어서 지운 것이 맞아요. 약해진 곳은 `d44_...` 하나예요 (1번).
