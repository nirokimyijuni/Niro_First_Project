## M1 캐릭터가 움직여요
> M1 범위: 타이틀 → 캐릭터 고르기 → 땅 위에서 걷기·점프·대기, 장애물 넘기.
> M1에 넣지 않는 것: 몬스터, 코인, 낮/밤, 모바일 조이스틱(M7).
> 걷는 빠르기, 점프 높이 같은 수치는 `game/src/config.rs`에 둔다.

### US-002 타이틀 화면에 "미스 찾기"가 나온다  [M1] [완료]
플레이어로서, 게임을 켜면 "미스 찾기"라는 제목을 보고 싶다. 그래야 우리가 만든 게임이라는 걸 알 수 있다.
완료 조건:
- [x] 링크를 열면 맨 처음 타이틀 화면이 나온다
- [x] 화면 가운데 위쪽에 **미스 찾기** 가 한글로 나온다 (네모 칸이나 깨진 글자가 없다)
- [x] 제목 글자가 Jua 폰트다 (둥글둥글한 손글씨 느낌, 일반 글꼴과 다르게 보인다)
- [x] 제목 아래에 "Enter나 Space를 누르거나 화면을 눌러요" 같은 안내 문구가 나온다
- [x] Enter, Space, 마우스 클릭, 화면 터치 중 하나를 하면 캐릭터 고르기 화면으로 넘어간다
- [x] 다른 키(예: A, ←)를 누르면 넘어가지 않는다
아이에게 물어볼 것: 타이틀 화면 제목은 무슨 색이면 좋을까? 제목 옆에 캐릭터 그림도 넣을까?

### US-003 Niro, Ellie, Logan 중 한 명을 고른다  [M1] [완료]
플레이어로서, 세 캐릭터 중 마음에 드는 한 명을 골라서 놀고 싶다. 그래야 내가 좋아하는 캐릭터로 게임을 할 수 있다.
완료 조건:
- [x] 캐릭터 고르기 화면에 Niro, Ellie, Logan 세 명이 나란히 보이고, 각 그림 아래에 이름이 쓰여 있다
- [x] 처음 들어오면 한 명(맨 왼쪽 Niro)이 골라진 표시(테두리나 화살표)가 있다
- [x] → 를 누르면 표시가 오른쪽 캐릭터로, ← 를 누르면 왼쪽 캐릭터로 옮겨 간다
- [x] 맨 왼쪽에서 ← 를 누르거나 맨 오른쪽에서 → 를 눌러도 화면이 멈추거나 표시가 사라지지 않는다
- [x] Enter나 Space를 누르면 표시된 캐릭터로 게임이 시작된다
- [x] 마우스로 캐릭터를 클릭하거나 화면에서 손가락으로 누르면 그 캐릭터로 게임이 시작된다
- [x] 세 명을 각각 한 번씩 골라 봤을 때, 게임 화면에 나오는 캐릭터가 고른 캐릭터와 같다 (옷 색깔로 확인: Niro 노란 상의, Ellie 파랑·분홍 옷, Logan 빨간 상의)
엘리 메모: Ellie(가운데)를 고르면 주황 화살표가 제목 글자에 살짝 겹친다 (qa/bugs/BUG-002, 낮음, 완료 조건에는 영향 없음).
아이에게 물어볼 것: 캐릭터를 고를 때 화면에 뭐라고 쓸까? (예: "누구랑 모험할래?")

### US-004 ←/→ 로 걷고, 걷는 쪽을 바라본다  [M1] [완료]
플레이어로서, 화살표 키로 캐릭터를 걷게 하고 싶다. 그래야 땅 위를 돌아다닐 수 있다.
완료 조건:
- [x] → 를 누르고 있으면 캐릭터가 오른쪽으로 걷고, 손을 떼면 멈춘다
- [x] ← 를 누르고 있으면 캐릭터가 왼쪽으로 걷고, 손을 떼면 멈춘다
- [x] 걷는 동안 걷기 동작(다리가 움직이는 그림)이 나온다 — 엘리 확인: 원화가 한 장이라 다리 대신 몸 전체가 통통 튀고 좌우로 기우뚱한다. 걷는 느낌은 충분. 진짜 다리 움직임은 아이가 걷기 그림을 더 그려 주면 가능
- [x] 오른쪽으로 걸으면 캐릭터가 오른쪽을 보고, 왼쪽으로 걸으면 그림이 뒤집혀 왼쪽을 본다
- [x] 걷다가 멈추면 마지막에 걷던 쪽을 계속 보고 있다
- [x] ←와 →를 같이 누르면 캐릭터가 이상하게 떨리지 않는다 (멈추거나 한쪽으로만 간다)
아이에게 물어볼 것: 캐릭터가 걸을 때 발소리가 날까? 난다면 어떤 소리?

### US-005 Space나 ↑ 로 점프한다  [M1] [완료]
플레이어로서, 점프를 하고 싶다. 그래야 장애물을 넘을 수 있다.
완료 조건:
- [x] 땅에 서 있을 때 Space를 누르면 캐릭터가 위로 뛰었다가 다시 땅에 내려온다
- [x] ↑ 를 눌러도 똑같이 점프한다
- [x] 점프하는 동안 점프 그림(동작)이 나온다
- [x] 공중에 있을 때 Space나 ↑ 를 또 눌러도 더 높이 올라가지 않는다 (공중에서 또 점프 안 됨)
- [x] Space를 계속 누르고 있어도 캐릭터가 하늘로 날아가지 않는다
- [x] 점프하면서 ←/→ 를 누르면 그쪽으로 날아가듯 움직이고, 그쪽을 바라본다
- [x] 점프해도 캐릭터 머리가 화면 위로 잘려 나가지 않는다
아이에게 물어볼 것: 점프할 때 캐릭터가 "얍!" 같은 소리를 낼까? 뭐라고 할까?

### US-006 가만히 있으면 대기 동작을 한다  [M1] [완료]
플레이어로서, 키를 안 누르고 있을 때도 캐릭터가 살아 있는 것처럼 움직였으면 좋겠다.
완료 조건:
- [x] 게임이 시작되고 아무 키도 안 누르면 캐릭터가 땅에 서서 대기 동작(숨쉬듯 살짝 움직이기 등)을 한다
- [x] 걷다가 키를 떼면 걷기 동작이 멈추고 대기 동작으로 바뀐다
- [x] 점프하고 땅에 내려와 아무 키도 안 누르면 대기 동작으로 바뀐다
- [x] 대기 동작은 계속 반복되고, 중간에 캐릭터가 사라지거나 깜빡이지 않는다
- [x] 대기 동작 중에도 바라보던 방향(왼쪽/오른쪽)은 그대로다
아이에게 물어볼 것: 가만히 있을 때 캐릭터가 뭘 하면 좋을까? (하품하기, 손 흔들기, 두리번거리기…)

### US-007 땅 위에 넘어야 할 장애물(상자)이 있다  [M1] [완료]
플레이어로서, 길에 놓인 상자를 점프로 넘거나 그 위에 올라서고 싶다. 그래야 걷기만 하는 게 아니라 점프하는 재미가 있다.
완료 조건:
- [x] 게임 화면 아래쪽에 땅이 보이고, 캐릭터는 땅 위에 서 있다 (땅 아래로 빠지지 않는다)
- [x] 땅 위에 상자 같은 장애물이 2개 이상 있다
- [x] 걸어서 상자 옆으로 가면 상자에 막혀 더 못 간다 (상자 속으로 들어가거나 뚫고 지나가지 않는다)
- [x] 왼쪽에서 와도, 오른쪽에서 와도 똑같이 막힌다
- [x] 상자 앞에서 점프하면 상자를 넘어갈 수 있다
- [x] 점프해서 상자 위에 내려오면 상자 위에 서 있을 수 있고, 거기서 걷기·점프·대기가 모두 된다
- [x] 상자 위에서 걸어 끝을 지나면 땅으로 떨어져 내려온다
- [x] 점프로 아래에서 상자에 부딪혀도 상자 속에 끼지 않는다
아이에게 물어볼 것: 장애물은 상자가 좋을까, 아니면 바위·나무 그루터기 같은 다른 게 좋을까? 몇 개 놓을까?

### US-008 캐릭터가 화면 밖으로 나가지 않는다  [M1] [완료]
플레이어로서, 캐릭터가 화면 밖으로 사라지지 않았으면 좋겠다. 그래야 캐릭터를 잃어버리지 않는다.
완료 조건:
- [x] 화면 왼쪽 끝까지 걸어가면 캐릭터가 거기서 멈추고, 몸이 화면 밖으로 잘려 나가지 않는다 (BUG-001 닫힘, 엘리 재확인 2026-11-01)
- [x] 화면 오른쪽 끝까지 걸어가면 캐릭터가 거기서 멈추고, 몸이 화면 밖으로 잘려 나가지 않는다 (BUG-001 닫힘, 엘리 재확인 2026-11-01)
- [x] 화면 끝에서 점프하면서 바깥쪽 화살표를 눌러도 밖으로 나가지 않는다
- [x] 브라우저 창 크기를 바꾼 뒤에도 캐릭터가 화면 안에 있다
참고: M1은 한 화면 크기의 맵이다. 화면이 옆으로 따라가는(스크롤) 넓은 맵은 나중 단계에서 정한다.
아이에게 물어볼 것: 화면 끝에 가면 그냥 멈출까, 아니면 벽이나 나무 같은 걸 그려 둘까?

## M2 낮과 밤
> M2 범위: 낮 10분 / 밤 10분 시계, 해변 하늘 바뀌기(낮 → 노을 → 밤 → 새벽 → 낮), 화면 위 정보판(HUD), 상자 위 코인 줍기, 개발용 빨리감기(F).
> M2에 넣지 않는 것: 몬스터(M3), 저장(M3 이후), 모바일 조작(M7).
> 수치(낮/밤 길이, 노을·새벽 길이, 코인 다시 생기는 시간, 코인 상한, 빨리감기 배수)는 `game/src/config.rs`에 둔다. 근거: docs/02-plan.md D1, D4, D9~D12.
> 엘리 확인 팁: 빨리감기(F, US-010)를 켜면 낮 10분이 **1분**, 밤 10분도 **1분**, 노을·새벽 1분이 **6초**, 코인 10초가 **1초**가 된다.
> 24시간 시계 기준(D14, US-016): 보통은 실제 1초 = 게임 **1.2분**, 빨리감기면 실제 1초 = 게임 약 **12분**. 빨리감기에서 낮 06:00~18:00 = 약 **1분**, 밤 18:00~06:00 = 약 **1분**, 노을(16:48~18:00)·새벽(04:48~06:00) = 약 **6초**, 게임 하루 24시간 = 약 **2분**.

### US-009 낮 10분, 밤 10분 시계가 돈다  [M2] [완료]
플레이어로서, 지금이 낮인지 밤인지, 얼마나 남았는지 알고 싶다. 그래야 밤이 오기 전에 준비할 수 있다.
완료 조건:
- [x] 캐릭터를 고르고 게임이 시작되면 화면 위 정보판에 **낮** 과 남은 시간 **10:00** 이 나온다 (1일째 아침에 시작) (US-016에서 24시간 시계로 바뀜)
- [x] 남은 시간이 1초마다 1씩 줄어든다 (10:00 → 09:59 → 09:58 …). 휴대폰 초시계로 1분 재면 정보판도 1분(09:00) 줄어 있다 (US-016에서 24시간 시계로 바뀜)
- [x] 남은 시간은 언제나 "분:초" 두 자리씩이다 (예: 09:05, 00:07). 음수(-00:01)나 10:00보다 큰 숫자는 나오지 않는다 (US-016에서 24시간 시계로 바뀜)
- [x] 낮이 00:00이 되면 **밤** 으로 바뀌고 남은 시간이 다시 10:00부터 줄어든다 (US-016에서 24시간 시계로 바뀜)
- [x] 밤이 00:00이 되면 다시 **낮** 으로 바뀌고 10:00부터 줄어든다 — 이렇게 끝없이 반복된다 (US-016에서 24시간 시계로 바뀜)
- [x] 걷기·점프 중에도, 가만히 서 있어도 시계는 똑같이 간다
- [x] 빨리감기로 확인: F를 켜고 약 1분 기다리면 낮 → 밤, 또 약 1분 기다리면 밤 → 낮으로 바뀐다. 3번 이상 바뀌어도 멈추거나 숫자가 이상해지지 않는다
- [x] 다른 브라우저 탭에 30초 갔다가 돌아와도 게임이 멈추거나 낮/밤을 여러 번 한꺼번에 건너뛰지 않는다
엘리 메모(M2): 실제 1분 = 정보판 1분 확인(09:48→08:48). "다른 탭 30초"는 브라우저 패널에서 탭이 숨겨지지 않아, 메인 스레드를 20초 막아 긴 프레임을 흉내 냄 → 시계가 약 3초만 감(한꺼번에 안 건너뜀) + main.rs 단위 테스트. 주의: 초당 4프레임 아래로 느린 기기에서는 시계가 실제보다 느리게 간다(한 프레임 최대 0.25초) — 보통 폰·PC는 괜찮음.
아이에게 물어볼 것: 남은 시간 옆에 해와 달 그림을 넣을까? 시계 그림이 좋을까?

### US-010 F 키로 시간을 10배 빠르게 한다 (개발용)  [M2] [완료]
만드는 사람(엘리·조슈아·로건)으로서, 10분을 다 기다리지 않고 낮/밤과 코인을 확인하고 싶다. 그래야 빨리 고치고 확인할 수 있다.
완료 조건:
- [x] 게임 중 F를 한 번 누르면 빨리감기가 켜지고, 화면에 **빨리감기 x10** 같은 표시가 보인다
- [x] 켜져 있을 때 남은 시간이 1초에 약 10초씩 줄어든다 (휴대폰 초시계로 6초 재면 약 1분 줄어 있다)
- [x] 켜져 있을 때 주운 코인이 약 1초 만에 다시 생긴다 (US-014)
- [x] 빨리감기를 켜도 캐릭터가 걷는 빠르기와 점프 높이는 그대로다 (시계와 코인 시간만 빨라진다)
- [x] F를 다시 누르면 꺼지고, 표시가 사라지고, 시계가 원래 빠르기(1초에 1초)로 돌아온다
- [x] F를 꾹 누르고 있어도 켜졌다 꺼졌다 깜빡이지 않는다 (누를 때 한 번만 바뀐다)

### US-036 PC에서는 조이스틱·버튼 없이 키보드 그대로  [M3] [테스트 중]
