# BUG-003 폰 세로 화면(375×812)에서 안내 글씨가 너무 작음
- 관련 스토리: US-001 (폰 확인은 M7), US-002·US-003 안내 문구
- 심각도: 낮음 (M7에서 꼭 다시 보기). 화면이 잘리지는 않음.
- 재현: 1) 브라우저를 모바일 크기 375×812로 연다 2) 타이틀 → 캐릭터 고르기 → 게임 화면을 본다
- 기대: 8살 아이가 폰을 세로로 들고도 안내 문구를 읽을 수 있다
- 실제: 게임 화면이 375×211 크기로 가운데에만 작게 나오고 위아래는 빈 띠다.
  그래서 글씨 크기가 실제로 대략
  - 타이틀 안내 "시작하려면 Space/Enter 또는 화면을 눌러요": 약 15px (게다가 깜빡일 때 흐려짐)
  - 고르기 화면 아래 안내: 약 12px
  - 게임 화면 위 안내 "화살표: 걷기 ...": 약 11px
  로 아이가 읽기 어렵다. 캐릭터 카드 이름(Niro 등)은 약 16~20px로 읽힌다.
  가로로 돌리면(812×375) 글씨가 충분히 크다.
- 제안: M7에서 "폰을 옆으로 돌려 주세요" 안내를 띄우거나, 세로 화면용 배치를 따로 두기. 아이에게 물어볼 거리로 남겨도 좋음.
- 고칠 사람: 로건 (M7)
- 환경: Chrome 모바일 크기 375×812 (DPR 2 에뮬레이션)
