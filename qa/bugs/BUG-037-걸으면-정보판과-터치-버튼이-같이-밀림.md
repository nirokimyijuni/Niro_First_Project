# BUG-037 걸으면 정보판(HUD)·조이스틱이 카메라와 같이 밀림
- 관련 스토리: 아이폰·카톡 화면 꽉 채우기 (스토리 번호 없음, 부모 요청 2026-11-21)
- 관련 리뷰: 없음 (작은 고침으로 밥 리뷰 건너뜀)
- 심각도: S1 제안 (플레이하면 바로 보이고, 걸을수록 정보판·퀴즈 창·터치 버튼이 화면 밖으로 밀림)
- 발견 시점: 시험
- 영역: 화면
- 원인: 코드 (맵을 그린 뒤 화면 좌표로 되돌리는 look_at(0.0) 한 줄이 지워져 있었다. 로건이 되돌리고 소스 순서를 확인하는 시험 hud_is_drawn_with_the_screen_camera_after_the_map을 더함)
- 재현: 1) PC에서 게임 열기 (960×540처럼 딱 16:9 창이 가장 잘 보임) 2) Niro 고르기 3) 오른쪽으로 2~3초 걷기
- 기대: 얼굴·체력 막대·미션 글·조이스틱이 걸어도 같은 자리
- 실제: 걷는 만큼 왼쪽으로 밀림 (스크린샷 기준 얼굴 x 163 → 140, 조이스틱 x 342 → 318). 812×375에서는 잠깐 퀴즈 창이 오른쪽으로 밀려 글이 잘려 보임. 터치 누르는 자리는 안 밀리므로 화면과 손가락 자리가 어긋날 수 있음 (BUG-008 같은 모양)
- 환경: Chrome PC, 960×540 / 812×375 (직접 확인). 진짜 폰은 못 봄
- 상태: 닫힘 (엘리 2026-11-21 다시 확인: 960×540·812×375·667×375에서 오래 걸은 뒤 얼굴·체력·조이스틱·시계 자리 그대로, 가방·퀴즈 창 제자리, 퀴즈 숫자판 좌표 클릭이 그림과 맞음. 세로 375×812는 걷기 전만 봄. cargo test 120개 통과)
