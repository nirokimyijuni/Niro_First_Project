# BUG-032 몬스터 위 "쓰러졌어요" 글이 쿵 작은 줄과 정보판 물건 줄에 겹침
- 관련 스토리: US-081, US-082
- 관련 리뷰: REVIEW-020
- 심각도: S4 (엘리 제안: 1초쯤 떠올랐다 사라지고, 큰 쿵 글은 다 읽힌다)
- 발견 시점: 시험
- 영역: 화면
- 원인: 코드 (머리 위 "쓰러졌어요"는 맵 좌표로 떠올라서 정보판·큰 알림 글 자리를 보지 않았다)
- 재현: 1) `?qa`로 새 게임(Niro) 2) 1, 2, 3 키, G로 엔더열매 먹기 3) 밤에 몬스터가 캐릭터 가까이 왔을 때 해변에서 E로 쿵
- 기대: 쓰러진 몬스터 위의 "쓰러졌어요" 글이 쿵 글과 정보판 글에 안 겹친다
- 실제: 740×360에서 캐릭터 옆 몬스터의 "쓰러졌어요"가 "다이아몬드를 10개 얻었어요!" 줄 바로 아래에 겹쳐 뜬다. 960×540에서는 떠오르던 "…었어요" 글이 정보판 물건 줄(스케이트·갑옷 시간) 위를 지나갔다
- 환경: 앱 브라우저 PC 960×540, 740×360, dist 312ab00-20261114214059 (커밋 전 작업 트리)
- 담당: 로건
- 상태: 고침 (로건 2026-11-15, US-091과 함께. 원인: "쓰러졌어요"가 정보판·큰 알림 글 자리를 보지 않고 떠올랐다. 이제 떠오르는 칸이 정보판·큰 글과 겹치면 별만 보이고 글은 빼낸다. 엘리 확인 필요)
- 엘리 재확인 (2026-11-15, 일부): 960×540에서 주사기총으로 두 마리를 쓰러뜨렸을 때 "쓰러졌어요"가 1초 안에 사라지고 정보판에 닿지 않았다. 원래 재현(740×360에서 해변 바닷가 쿵)은 쿵 자리를 못 잡아 **못 봄**. 그래서 닫지 않는다
