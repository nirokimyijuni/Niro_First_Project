# BUG-003 폰 세로 화면(375×812)에서 안내 글씨가 너무 작음
- 관련 스토리: US-001 (폰 확인은 M7), US-002·US-003 안내 문구
- 심각도: 낮음 (M7에서 꼭 다시 보기). 화면이 잘리지는 않음.
- 재현: 1) 브라우저를 모바일 크기 375×812로 연다 2) 타이틀 → 캐릭터 고르기 → 게임 화면을 본다
- 기대: 8살 아이가 폰을 세로로 들고도 안내 문구를 읽을 수 있다
- 실제: 게임 화면이 375×211 크기로 가운데에만 작게 나오고 위아래는 빈 띠다.
  그래서 글씨 크기가 실제로 대략
  - 타이틀 안내 "시작하려면 Space/Enter 또는 화면을 눌러요": 약 15px (게다가 깜빡일 때 흐려짐)
  - 고르기 화면 아래 안내: 약 12px
  - 게임 화면 위 안내 "화살표: 걷기 ...": 약 11px
  로 아이가 읽기 어렵다. 캐릭터 카드 이름(Niro 등)은 약 16~20px로 읽힌다.
  가로로 돌리면(812×375) 글씨가 충분히 크다.
- 제안: M7에서 "폰을 옆으로 돌려 주세요" 안내를 띄우거나, 세로 화면용 배치를 따로 두기. 아이에게 물어볼 거리로 남겨도 좋음.
- 고칠 사람: 로건 (M7)
- 환경: Chrome 모바일 크기 375×812 (DPR 2 에뮬레이션)

## M7 다시 보기 (2026-11-02, 엘리)
- 세로 화면: 터치 모드가 켜지면(첫 톡 뒤) "가로로 돌려 주세요" 안내가 화면 전체에 나와서 세로로 플레이할 일이 없어졌다. 안내 글씨는 375×812에서 약 37px, 408×906에서 약 40px (24px 이상 조건 통과). → 세로 화면 문제는 **해결**.
- 단, 링크를 세로로 열고 아직 한 번도 안 만졌을 때는 타이틀이 예전처럼 작게 보인다 (US-035 바뀐 조건대로라 버그 아님).
- 가로 화면 글씨 크기 (글꼴 크기, 브라우저 CSS px, 코드 크기 × 화면 배율로 계산하고 스크린샷으로 눈으로 확인):
  | 글씨 | 740×360 (배율 0.667) | 844×390 (배율 0.722) |
  |---|---|---|
  | 정보판 시각·코인 (38) | 약 25px | 약 27px |
  | 정보판 "1일째 버틴 날" (34) | 약 23px | 약 25px |
  | "점프", "고르기" 버튼 글씨 (32) | 약 21px | 약 23px |
  | 타이틀 안내 (38) | 약 25px | 약 27px |
  | 고르기 화면 아래 안내 (30) | 약 20px | 약 22px |
  | 타이틀 구석 버전 표시 (18) | 약 12px | 약 13px (일부러 작게, 어른용) |
  모두 읽을 만하다. 가장 작은 고르기 안내(20px)도 브라우저 화면에서는 읽혔다.
- 남은 것: (실제 폰) 가로 화면에서 정보판·돌아가기 버튼 글씨가 읽을 만한지 (US-035)

## M3 마무리 결과 (2026-11-06, 엘리)
- 실제 폰: 부모님이 안드로이드 폰 라이브(ac750ad)의 가로 화면에서 글씨·그림이 안 깨진다고 확인했다.
- 세로 화면: "가로로 돌려 주세요" 안내로 해결 (US-035). 가로 화면 글씨: 위 표대로 가장 작은 고르기 안내도 약 20px.
- 남은 메모: 링크를 세로로 열고 아직 안 만진 타이틀은 작게 보이지만 US-035 조건대로라 버그가 아니다. 아이가 직접 읽어 본 확인은 없다.
- 상태: 닫힘
