# BUG-002 가운데 캐릭터(Ellie)를 고르면 위쪽 화살표가 "캐릭터를 골라요" 글자에 겹침
- 관련 스토리: US-003
- 심각도: 낮음 (보기에만 조금 거슬림, 조작에는 문제 없음)
- 재현: 1) 타이틀에서 Enter 2) 캐릭터 고르기 화면에서 → 한 번 눌러 Ellie를 고른다
- 기대: 골라진 표시(주황 세모 화살표)가 제목 글자와 떨어져서 보인다
- 실제: 주황 세모가 위아래로 통통 튀면서 제목 "캐릭터를 골라요"의 "를" 아래쪽에 겹친다
  (세모 위 끝이 가상 y≈69~79, 제목 글자 바닥선이 y=80)
- 참고: Niro·Logan을 고를 때는 세모가 제목 글자 옆이라 겹치지 않는다
- 고칠 사람: 로건 (`view/screens.rs` 제목 위치 또는 세모 위치)
- 환경: Chrome PC
- 상태: 닫힘 (엘리 재확인 2026-11-01)
- 재확인 결과 (Chrome PC): Ellie를 고른 상태에서 30프레임 동안 잰 주황 세모 위 끝은 가장 높아도 가상 y≈74, 제목 글자 바닥은 가상 y≈67 → 약 7px 떨어져 겹치지 않음. 눈으로도 떨어져 보임. `pick_arrow_stays_below_select_title` 통과.
- 고친 방법: (로건) 제목 "캐릭터를 골라요" 바닥선을 y=80 → 62로 올리고, 세모를 조금 작게(높이 22→20, 튀는 폭 5→4, 카드와 간격 14→12) 해서 세모 위 끝이 가장 높아도 y=74 (제목 바닥선보다 12px 아래). 테스트 `pick_arrow_stays_below_select_title` 추가.
