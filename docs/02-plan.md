# 개발 계획

## 큰 그림
**"매 단계마다 아이가 직접 해볼 수 있는 게임"** 을 만든다. 처음부터 다 만들지 않고, 작은 단계(마일스톤)마다 링크로 플레이해 보고 다음 단계로 넘어간다.

## 기술 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 엔진 | **macroquad** | Wasm 빌드가 `cargo build` 한 줄, 설정이 거의 없음. bevy는 무겁고 배우기 어려움 |
| 화면 | 2D 옆에서 보는 시점(횡스크롤) | 지침의 "점프로 장애물 피하기"에 맞음 |
| 그림 | 아이 원화를 스캔 → 단순 픽셀/벡터 스프라이트 | 아이 그림의 느낌을 살림 |
| 배포 | GitHub Pages | 무료, 링크 하나로 공유 |
| 모바일 | 화면 위 가상 조이스틱 + 점프/공격 버튼 | 지침의 반응형 요구 |

### 코드 구조 (수산나 ↔ 로건 경계)
```
game/src/
  main.rs        ← 게임 루프: 입력 → logic 업데이트 → view 그리기
  config.rs      ← 모든 게임 수치 (시간, 공격 횟수, 코인 상한…)
  logic/         ← 수산나: 화면을 모르는 순수 규칙 (테스트 가능)
    player.rs  monster.rs  combat.rs  clock.rs  level.rs  mine.rs  shop.rs
  view/          ← 로건: 그리기, 애니메이션, UI, 입력, 사운드
    sprites.rs  hud.rs  popup.rs  input.rs  audio.rs
```
`logic`은 macroquad 그리기 함수를 쓰지 않는다 → 엘리가 브라우저 없이 `cargo test`로 규칙을 검사할 수 있다.

## 마일스톤
각 단계 끝에 케빈이 링크를 올리고, 아이가 플레이해 본다.

| # | 이름 | 내용 | 아이와 함께 할 일 |
|---|---|---|---|
| M0 | 준비 | Rust 설치, macroquad "안녕" 화면, GitHub Pages 자동 배포 | 게임 제목 정하기 |
| M1 | 캐릭터가 움직여요 | 캐릭터 선택 화면, 걷기·점프·대기 애니메이션, 땅과 장애물 | 캐릭터 그림 다시 그리기(앞/옆/점프) |
| M2 | 낮과 밤 | 낮/밤 타이머(각 10분), 하늘 색 변화, 남은 시간·생존 시간 표시, 코인 줍기 | 밤 하늘 색 고르기 |
| M3 | 폰에서도! | 화면 조이스틱·점프 버튼, 폰에서 링크로 열기(GitHub Pages), 가로 안내, 버전 표시 (원래 M7에 있던 것을 앞당김) | 조이스틱·버튼 모양과 색 정하기, 폰으로 해 보기 📱 |
| M4 | 좀비가 나타났다 | 좀비, 공격(폰 공격 버튼 포함), 좀비 체력 3, 플레이어 체력 7, 게임오버·다시하기, 최고 기록 저장 | 좀비 모양·이름 정하기 |
| M5 | 스켈레톤과 레벨업 | 스켈레톤 화살 공격, 경험치·레벨업(체력 +5, 몬스터 레벨 상승) | 레벨업 효과음 녹음? |
| M6 | 제작과 동굴 탐험 | 나무·철 모으기, 4×3 제작대에서 곡괭이 만들기, 동굴, 랜덤 광석, 결과 팝업 + 사운드 (폰 캐기 버튼 포함) | 곡괭이 모양 그리기, 광석 종류·희귀도 정하기 |
| M7 | 상점 | 코인(최대 5,000)으로 아이템·장비 구매 | 상점에 팔 물건 정하기 |
| M8 | 저장과 다듬기 | 레벨·코인·아이템 저장, 화면 크기 대응 다듬기, 누가 오래 버텼나 기록 | 가족끼리 누가 오래 버티나 대결 🎉 |
| M9 | 정식 릴리즈 (AWS) | 모든 마일스톤이 끝난 뒤 S3 + CloudFront로 배포, 내 도메인 연결, 자동 배포를 AWS로 전환 (D18) | 도메인 이름 정하기, 가족에게 링크 보내기 🎉 |

## 결정 사항 (2026-11-01 결정)
원본 지침과 다르게 정한 것. **원본 지침보다 이 표가 우선한다.**

| # | 주제 | 결정 | 남은 질문 |
|---|---|---|---|
| D1 | 낮/밤 시간 | **낮 10분 / 밤 10분** (원본: 5분/20분) | — |
| D2 | 플레이어 체력 | 하트(HP) 방식. **시작 체력 7**, 레벨이 오를 때마다 **+5** (7 → 12 → 17…). 맞으면 몬스터 공격력만큼 줄고, 0이 되면 게임오버 | — |
| D3 | 몬스터 강해지기 | 플레이어 레벨이 오르면 **몬스터 레벨도 오른다.** 몬스터 체력은 레벨이 올라도 그대로. **좀비 체력 3**(3번 때리면 쓰러짐). **좀비 공격력은 5에서 시작해 레벨마다 −2** (레벨 1: 5 → 레벨 2: 3 → 레벨 3: 1). 공격력이 0이나 음수가 되면 안 되므로 **최소 1**로 둔다 — 레벨 3부터는 계속 1 (아이가 "괜찮아"라고 함). (원본의 "공격 횟수 레벨당 +1"은 쓰지 않음) | — |
| D4 | 이기는 방법 | 끝이 없다. **누가 더 오래 살아남는지** 겨룬다 → **버틴 날 수**(밤을 넘긴 횟수)를 기록으로 보여준다 | — |
| D5 | 곡괭이 | **제작대**에서 만든다. 제작대는 **가로 4칸 × 세로 3칸**. 아래 모양대로 **나무 4개 + 철 블럭 2개**를 놓으면 곡괭이가 나온다. **나무는 맵에서** 얻는다. **철은 동굴의 랜덤 광석**에서 얻는다 — 가장 자주 나오는 게 철이고, 다른 광물도 나올 수 있다. 곡괭이가 없을 때는 **맨손으로 캔다. 맨손은 곡괭이보다 느리다** (처음 값: 맨손 3초, 곡괭이 1초 — M5에서 해 보고 조절) | — |
| D6 | 저장 | **가능.** 브라우저 저장 공간(localStorage)에 저장한다. 후보 크레이트 `quad-storage` (macroquad 버전 호환은 M0에서 확인). 최고 기록은 **M4**에, 레벨·코인·아이템 저장은 **M8**에. 다른 기기·다른 브라우저에서는 안 보이고, 브라우저 데이터를 지우면 사라진다 | — |
| D7 | 게임 제목 | **미스 찾기**. 제목 글씨는 자모마다 색이 다르다: 미(ㅁ 초록, ㅣ 핑크) 스(ㅅ 파랑, ㅡ 주황) 찾(ㅊ 빨강, ㅏ 노랑, ㅈ 하양) 기(ㄱ 검정, ㅣ 회색) | — |
| D9 | 배경 | **해변**: 하늘, 바다(뒤쪽 배경), 물결, 모래 땅. 바다에 들어가는 규칙은 없음 | — |
| D10 | 밤하늘 | **남색** 하늘에 **별과 달**. 바다도 함께 어두워진다 | — |
| D11 | 코인 | **금색 동그라미**. **상자 위**에 하나씩 놓인다. **주우면 다시 생긴다** (처음 값: 10초 뒤 같은 자리에 — Claude가 정한 값, 해 보고 조절). 하나에 1코인, 최대 5,000 | — |
| D12 | 빨리감기 (개발용) | **F 키**를 누르면 시간이 10배 빨라지고, 다시 누르면 원래대로. 켜져 있으면 화면에 표시. 아이와 할 때는 꺼 둔다 | — |
| D13 | 낮·밤 세부 (니로 해석) | 노을·새벽은 낮·밤의 **마지막 1분**. "N일째"와 "버틴 날"은 **밤이 끝나 아침이 될 때** 1씩 는다 (시작: 1일째, 버틴 날 0). 빨리감기는 시계·코인 시간만 빠르게, 새 게임 때는 꺼진 상태. 코인 5,000이면 주워도 그대로 | — |
| D14 | 24시간 시계 | 정보판 시계는 남은 시간을 거꾸로 세지 않고, **24시간 시계처럼 앞으로** 간다 (HH:MM). 게임 하루 24시간 = 실제 20분. **낮 06:00~18:00**, **밤 18:00~06:00**. 실제 1초 = 게임 1.2분. 06:00에 N일째·버틴 날 +1 (D13 그대로). 아이가 "시간이 줄어드는 것처럼 보여"라고 발견 | — |
| D15 | 그래픽 방향 | 엔진은 **macroquad 그대로**, 그리는 방식을 업그레이드 (A안). 해·달·하늘·구름부터: 부드러운 빛(글로우), 자연스러운 그라데이션, 깊이감(패럴랙스). 아이가 그린 캐릭터는 손그림 그대로 두고 주변을 세련되게. 그림 파일은 내려받지 않고 코드·셰이더로 만든다 (나중에 아이·엄마 그림으로 바꿀 수 있게) | — |
| D16 | 폰 조작 | **화면 조이스틱** (아이가 고름). 왼쪽 절반 아무 곳이나 엄지를 대면 그 자리에 조이스틱이 생기고 좌우로 밀어 걷는다. 오른쪽에 큰 **점프** 버튼 (M4부터 공격, M6부터 캐기 버튼이 옆에 추가). 터치 화면에서만 보이고, PC는 키보드 그대로. 폰을 세로로 들면 "가로로 돌려 주세요" 안내. 원래 M7이던 것을 앞당겨 **M3**로 한다 (2026-11-02 로드맵 순서 변경) | ❓ 버튼 모양(동그라미·네모, 그림) |
| D17 | 폰에서 열기 | **GitHub Pages**로 배포: main에 push하면 자동으로 빌드·배포. 새 버전이 캐시 때문에 안 보이는 일이 없게 파일 주소에 버전을 붙인다 | — |
| D18 | AWS 릴리즈 | **모든 마일스톤(M0~M8)이 끝나면** (M9) AWS로 정식 릴리즈한다. 그전까지는 GitHub Pages. 방법 후보: S3 + CloudFront (+ Route 53 도메인, ACM 인증서), GitHub Actions에서 OIDC로 배포 (비밀 키 저장 안 함). 자기 도메인을 쓰면 주소에 GitHub 아이디가 안 보이고, 저장소를 다시 비공개로 돌릴 수 있다. 담당: 케빈 | ❓ 도메인 이름 |
| D8 | 캐릭터 이름 | 아이 그림처럼 영어 그대로: **Niro, Ellie, Logan** | — |
