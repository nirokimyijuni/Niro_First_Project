# BUG-014 폰 화면에서 오른쪽 스켈레톤이 점프 버튼에 가려짐
- 관련 스토리: US-046, US-048, M4 "버튼이 오른쪽 좀비와 셋째 상자를 가리는 느낌"
- 심각도: 낮음~보통 (쏘는 몬스터가 잘 안 보인다)
- 재현: 1) 812×375로 게임을 터치로 시작 2) 밤에 오른쪽 스켈레톤이 셋째 상자 뒤(x=828)에 멈출 때까지 기다린다
- 기대: 스켈레톤 몸이 보인다
- 실제: 머리만 버튼 위로 나오고 몸은 점프 버튼 그림 뒤에 들어간다. 상자 뒤 x=828이 스켈레톤이 늘 서는 자리라 자주 그렇다
- 고칠 사람: 로건 (버튼을 더 투명하게 하거나 자리를 옮김). 실제 폰에서 얼마나 거슬리는지 먼저 본다
- 환경: 내장 브라우저 812×375, 스크래치패드 임시 빌드 (화면 코드는 진짜와 같음)
- 상태: 열림
