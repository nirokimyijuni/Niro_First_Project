# BUG-013 창 크기를 바꾼 직후 정보판 글자가 까만 네모로 보임
- 관련 스토리: US-038, 정보판
- 심각도: S3 (엘리 제안: 글자가 잠깐 안 보이고 혼자 돌아온다. 실제 폰에서 오래 남으면 다시 정한다. 예전 표기 낮음)
- 재현: 1) 게임 중 창 크기를 바꾼다 (453×408 → 1200×700) 2) 바로 화면을 본다
- 기대: 글자가 그대로 보인다
- 실제: 정보판 윗줄 시계·날짜·코인 글자가 까만 네모로 보였다. 몇 초 뒤 찍은 화면은 정상. 같은 때 콘솔에 `glBindTexture called with an already deleted texture ID 25!`가 3번. 전에 기록만 해 둔 이 오류가 눈에 보이는 증상과 함께 나온 첫 사례다
- 재현은 한 번만 봤다. 폰을 돌릴 때도 나오는지는 못 봤다
- 고칠 사람: 로건
- 환경: 내장 브라우저, 진짜 dist 2e2bcb5-20261106131358
- 상태: 열림

## 추가 관찰 (엘리, 2026-11-07)
- 창 크기를 바꾸지 않아도 나왔다. 1200×700에서 새로 열고 시작해서 첫 판에 들어간 약 0.6초 뒤 화면에서 정보판 글자가 까만 네모였고, 약 10초 뒤 찍은 화면은 정상이었다. 콘솔에 `glBindTexture called with an already deleted texture ID 362!`가 6번 있었다
- 그래서 "창 크기를 바꾼 직후"만의 문제는 아니다. 처음 쓰는 글자를 글꼴 그림에 넣을 때 생기는 것일 수 있다 (추측, 원인은 안 봤다)
- 내장 패널은 프레임이 느려서 실제 폰보다 오래 보였을 수 있다. 실제 폰에서는 안 봤다
- 환경: 내장 브라우저, dist 2e2bcb5-20261106223138 (wasm은 아래 BUG-015대로 새 빌드로 바꿔 넣은 것)
