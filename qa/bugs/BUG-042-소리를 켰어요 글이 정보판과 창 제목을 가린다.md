# BUG-042 "소리를 켰어요/껐어요" 글이 다른 표시 위에 겹쳐 1초 동안 가린다
- 관련 스토리: US-112
- 관련 리뷰: (소리 시스템 리뷰, 밥)
- 심각도: S4
- 발견 시점: 시험
- 영역: 화면
- 원인: 코드. 글 자리가 화면 위쪽 가운데 고정 (view/audio.rs `draw_toast`, y=20)
- 재현: 1) 812×375로 새 판 시작 2) M 키 → 글이 정보판 "레벨" 글자와 가운데 위쪽을 덮음 3) Esc로 멈춤 창을 열고 M → 글이 "잠깐 멈췄어요" 제목과 "이어서 하기" 위쪽을 덮음 4) 타이틀(세로 창 694×950)에서 M → 로고 글자 "미스 찾기" 위를 덮음
- 기대: 다른 표시와 겹치지 않거나 겹쳐도 읽을 것은 읽힌다 / 실제: 1초 동안 제목·레벨 글자 일부가 가려짐 (읽기에는 지장 작음)
- 환경: Chrome PC 크기, 812×375 흉내
- 비고: 1초 뒤 사라지고 놀이에는 영향 없음. 로건이 자리(예: 아래쪽 가운데)를 옮길지 판단.
- 재확인 (엘리, 2026-11-21): 글이 아래 오른쪽으로 옮겨짐. 타이틀(세로 창), 플레이 960×540·812×375·세로 375×812에서 정보판·제목·로고·캐릭터·조이스틱을 안 가림. 멈춤 창이 열려 있을 때 M을 눌러도 글이 안 뜸. 못 본 것: 손에 든 칸에 물건이 있을 때 (코드 시험은 통과).
- 상태: 닫힘 (엘리)
